# RT1064 智能车程序

基于逐飞 RT1064、MT9V03X 摄像头和 IPS200 SPI 屏的循迹程序。

## 当前运行方式

- 正常循迹模式，处理弯道与十字，环岛关闭。
- 上电先停车并显示实时摄像头灰度图与边线。
- 短按并松开主板 **C15** 发车，按 **C13** 停车；不需要无线模块发车。
- 默认目标速度为 80（编码器计数/10ms），大转角和十字时降速。
- 左右电机分别使用编码器反馈调节输出。
- 屏幕 `Cr` 表示十字状态，`L`、`R` 表示各编码器通道的速度。

## 当前车体标定

S-U400 舵机使用 C30、50Hz PWM，满量程 10000：

| 位置 | PWM 数值 |
| --- | --- |
| 左端点 | 880 |
| 直行中位 | 760 |
| 右端点 | 670 |

按单轮点动结果修正后的电机输出：左轮 D3/D2，右轮 C11/C10。
编码器通道暂按左 C0/C1、右 C2/C24 配置；实车发车前，应在停车状态手转各轮，确认屏幕 L/R 与实际轮子对应。舵机端点和接线配置适用于当前车体，换车后需重新核对。

## 本次十字处理更新

- 边线搜索要求连续的黑白像素支撑，过滤孤立短边线段。
- 连续确认十字后补线；白区进入近处时，利用远端出口与最近近端锚点继续引导。
- 引导保持有时限，出口丢失或黑色遮挡时不生成近端引导线。

## 编译

用 Keil 打开 `project/mdk/rt1064.uvprojx`，选择目标 `nor_sdram_zf_dtcm`。当前使用 ARM Compiler 6.24。
编译生成 `project/mdk/Objects/rt1064.axf`；编译产物不纳入源码仓库。

主要配置：

- `project/user/src/main.c`：运行模式、按键、速度与转向参数。
- `project/code/Servo.h`：舵机标定与测试模式。
- `project/code/Screen.h`：屏幕类型和图像显示方式。

电机点动测试可将 `MOTOR_DIAGNOSTIC_MODE` 改为 1 后重新编译：架空驱动轮，按 C15 依次测试左右轮，C13 停止。正常循迹使用 0。

## 软件检查

需要 Python 3 和 GCC：

```text
python tests/run_vision_tests.py
python tests/run_servo_auto_tests.py
```

图像检查运行实际巡线、十字和偏差模块；舵机检查在临时目录选择自动往返分支，不改变工程的正常运行配置。软件检查不替代实车赛道验证。
