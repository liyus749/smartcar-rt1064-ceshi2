# 活动配置 AUTO180 R2

目录名称沿用R1回退配置；当前运行行为已更新为默认基础速度180、初始化和首帧有效图像后自动发车。主工程 `project/mdk/rt1064.uvprojx` 使用本目录的 `code/` 与 `user/`。

屏幕显示AUTO180 R2、二值图和边线、SPD/ERR、舵机P/D、左右轮实际/目标及RUN/WAIT/STOP。没有发车开关操作要求；S1=0仍可停车，故障或手动停车后不会自动重启。曲线数据仍为4通道，弯道降速和差速保留。

默认舵机P/D为1.80/2.00，电机PID为8/0.15/0；舵机C30/H5，中位790、左870、右715。普通中弯80、急弯70、前方预警100；出弯保持200ms，每20ms加2恢复。

`PROFILE.json` 与仓库 `firmware/manifest.json` 记录当前源码/固件信息。本机旧版备份不随Git提交。其他目录中的同名源码保留供原有开发任务使用，不参与当前默认构建。
