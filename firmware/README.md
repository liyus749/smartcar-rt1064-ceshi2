# KEY RUN R3 固件

当前请烧录 `rt1064_keys_R3.axf`。逐飞主板按键控制，无需无线模块。上电停车，C13启停，C12选SPD/P/D，C15减/C14加；默认SPD180、P1.80、D2.00，速度步进5、PD步进0.02。屏幕标题 `KEY RUN R3`，保留二值图及十字/环岛等状态。

构建、源文件校验和固件SHA256见 `manifest.json`，详细操作见 `../docs/逐飞主板_按键循迹R3.md`。电脑验证不能代替实车验证。

`rt1064_auto180.axf` 是历史AUTO180 R2无线版，上电取得图像后会自动启动；不用于此次按键控制。旧版清单保存在 `manifest_auto180_R2.json`。
