# RG2 四档速度配置

默认基础设定为180，取消原先弯道比例减速和80/70硬上限，保留RG1环岛识别修复。

| 场景 | 基础目标（编码器计数/10ms） |
| --- | ---: |
| 直道 | 180 |
| 小弯 | 160 |
| 大弯 | 140 |
| 环岛 | 100 |

## 速度选择

- 按原舵机控制量阈值30/60区分普通、小弯和大弯；不是车身转角的角度值。
- 图像前方弯道预警同样选择160或140档，不再额外压到100。
- 环岛优先采用100上限，转向和预警不会继续把它乘低；各环岛阶段均验证。即使有残留十字标志，也不再叠加十字比例。
- C15/C14仍可调整SPD。手动基础设定低于相应档位时保留较低设定，正常运行下限70和零速停车逻辑保持。
- 十字仍沿用原0.7比例，SPD180时基础目标126。
- 出弯仍先保持低目标200ms，再按每20ms增加2恢复，避免短暂直线间隙突然加速。

## 差速与屏幕

上述数字是差速前的基础目标，保留原外轮辅助差速和单轮240上限。稳定大弯在满差速时可以显示140/224；环内允许差速时可以显示100/160，入环/出环引导阶段为100/100。

屏幕SPD仍显示手动基础设定；左右轮斜杠后的数字是实际下发的各轮目标。标题旁的RG2用于确认本次固件。
