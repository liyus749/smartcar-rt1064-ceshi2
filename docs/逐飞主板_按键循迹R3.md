# 逐飞主板按键循迹 KEY RUN R3

使用 `project/mdk/rt1064.uvprojx`，目标 `nor_sdram_zf_dtcm`。活动源码位于 `project/restore_s1_R1/`。直接烧录 `firmware/rt1064_keys_R3.axf`，屏幕应显示 `KEY RUN R3`。

## 按键

| 主板按键/引脚 | 功能 |
| --- | --- |
| KEY3 / C13 | 发车、停车；每按一次切换一次，停车舵机回中 |
| KEY4 / C12 | 循环选择 SPD → P → D，屏幕 `>` 指示当前项 |
| KEY1 / C15 | 减小当前选中项 |
| KEY2 / C14 | 增大当前选中项 |

上电停车，默认选择SPD。SPD默认180，每次±5，范围70～240；舵机P默认1.80，范围0～5；D默认2.00，范围0～50，P/D每次±0.02。长按不连发，上电按住的键先松开后再按。只按C13会改变电机开关，选择/调参数不会发车。参数保存在RAM，断电恢复默认值。

无线VOFA与旧逐飞助手都关闭，不初始化无线模块，不接收无线参数也不发送图像/波形，无模块可直接运行。电机PID保留原默认8.00/0.15/0.00；弯道降速、差速、十字和纯图像环岛保留。

## 屏幕

- 摄像头二值图、左/中/右边线、十字/环岛补线和角点。
- RUN/STOP：发车开关状态；SPD：设定的基础速度；ERR：控制所用图像偏差。
- P/D：舵机PD，不是电机PID；`>` 标出按键当前调节项。
- L/R：左/右编码器实际值 / 该轮当前目标。单位为计数/10ms，不是RPM。弯道限速与差速后目标可以不同于SPD。
- PWM：舵机输出指令，中心790、左限870、右限715；并非实际转角测量。
- Cr：十字有效标志0/1；Cs：0普通、1候选、2进入、3内部、4驶出。
- Is：环岛阶段0普通、1接近、2等待入口、3入环、4环内、5出环、6对正、7恢复、8故障。
- Dir：LEFT左环／RIGHT右环／--未确认。
- CAM：OK当前有效，LOST图像不可用或超时；STOP:CAMERA表示丢图停车，STOP:RING表示环岛故障停车，STOP:--表示无故障停车原因。

## 启动与停车

初始化并看到正常图像后按C13发车，再按C13停车。无可用图像禁止发车；连续500ms无有效图像自动停机回中。图像恢复不会自动发车，再按C13启动。环岛故障同样停车；有有效图像时按C13清除故障并从下一新帧重新识别。

按原逐飞主板接口连接IPS200 SPI屏、摄像头和编码器，舵机仍使用C30信号口。换板后如左右编码器与实物不对应，需先核对接线。此次仅电脑模拟和编译验证，未代替实车检查。
