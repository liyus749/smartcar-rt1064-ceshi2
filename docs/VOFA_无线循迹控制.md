# AUTO180 R2 无线参数与屏幕

默认基础SPD180；上电完成初始化、首帧有效图像出现后自动循迹，不需要VOFA发车开关。摄像头无有效图像时等待。自动起步只执行一次，手动或故障停车后不会自行反复起步。

## VOFA设置

无线U12，UART8：D16发送、D17接收、D26 RTS。电脑端选择当前无线COM口，460800/8N1、无流控、FireWater。使用Str/ASCII发送，每条末尾为 `!`。

| 参数 | 绑定命令 | 默认值 | 范围 |
| --- | --- | --- | --- |
| 舵机P | `P1=%f!` | 1.80 | 0～5 |
| 舵机D | `D1=%f!` | 2.00 | 0～50 |
| 电机P | `P2=%f!` | 8.00 | 0～50 |
| 电机I | `I2=%f!` | 0.15 | 0～2 |
| 电机D | `D2=%f!` | 0.00 | 0～20 |
| 基础速度 | `V1=%f!` | 180 | 70～240 |

P/D调节可用0.02步进。每次只修改对应的一项，参数保存在RAM，断电回默认值。无需心跳、状态查询或阈值命令。

`S1=0!` 仍可手动停车；图像正常时 `S1=1!` 可手动恢复。正常开机无需发送S1。删除VOFA原发车控件即可，不要保留周期发送 `S1=0!` 的设置。

## 4个波形通道

| 通道 | 内容 |
| --- | --- |
| CH0 | 滤波后的图像偏差ErrUse |
| CH1 | 左编码器计数/10ms |
| CH2 | 右编码器计数/10ms |
| CH3 | 基础SPD，默认180 |

弯道仍自动降速和差速。普通中弯基础目标上限80、急弯70、前方预警100，出弯保持200ms，再每20ms加2恢复。环岛基础目标上限70，十字先乘0.7再按转向限制。比较PID跟踪效果应看屏幕的左右轮实际/目标，不应始终拿橙色基础SPD作为两轮即时目标。

## 精简屏幕

上方为BIN二值图与边线；下方为AUTO180 R2、运行状态、SPD/ERR、P/D、L实际/目标、R实际/目标。WAIT表示等待首帧有效图像，RUN表示循迹已开启，STOP表示已停车。接收计数、环岛阶段、限位与PWM极值等调试文字已移除。

## 源码与固件

主工程 `project/mdk/rt1064.uvprojx` 当前使用 `project/restore_s1_R1/` 中的活动源码。编译输出 `project/mdk/Objects/auto180/rt1064_auto180.axf`；GitHub仓库同时提供 `firmware/rt1064_auto180.axf`。

本机修改前备份保留在 `_已移除_旧文件备份/`，不随仓库上传。图像约500ms不更新、环岛故障或无线接收溢出等原有停车保护继续生效；普通无线断开本身不会触发停车。
