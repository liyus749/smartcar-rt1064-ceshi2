## 修改的生产源码

仅替换活动目录的四个环岛文件：

| 文件 | 作用 |
| --- | --- |
| `code/island.c` | 从旧 `E:\ceshi\island` 的活动工程保留一直调试的 VIS7 图像轮廓、上/中/下拐点、七阶段状态与补线实现，逐字节一致 |
| `code/island.h` | 同一套环岛参数、结构和接口，逐字节一致 |
| `code/Roundabout.h` | 保留旧环岛与电控之间的接口声明，使队友主程序的原调用继续有效 |
| `code/Roundabout.c` | 将队友程序的每帧处理、定时检查、故障重试、补线标志、显示锚点和路宽接口接入 VIS7 |

`Roundabout.c` 在原旧工程适配器基础上增加了一个交接保护：如果视觉确认出环的最后一帧仍含合成引导线，该帧暂保留恢复态，下一张干净图像再交回正常态。这样无需改队友的 `Err.c`，也能防止其正常路宽学习读入合成线。故障时该交接不会擅自清除故障或恢复正常运行。

## 完全保留的电控部分

主程序与中断、电机/舵机和标定、PID参数与闭环、差速、弯道预警与降速、基础找线、十字、显示、按键/无线配置及底层驱动均使用队友原文件。用合并前 SHA-256 清单逐文件核对，报告位于 `work/ring-transfer/verification.json`。

特别注意当前队友底版是 **KEY RUN R3**，不是以前的 VOFA 版本：

- 上电停车，C13 启动或停止。
- C12 循环选择 SPD/P/D；C15 减、C14 加。
- SPD 默认180，P默认1.80，D默认2.00，范围与步进完全使用队友程序。
- 无线模块默认关闭，没有恢复旧工程的 V1/S1 控制。
- 屏幕也保持队友版本，不带入旧 `VOFA MINI` 页面；原有环岛 `Is/Dir` 与图像锚点接口仍可显示本次 VIS7 的状态和点。

## 环岛工作方式

阶段为 0正常、1远处确认、2环口、3入环、4环内、5出环、6摆正、7恢复。判断来自当前图像的连续轮廓、同一弧段的上下端点和中间突出点，以及入环/出环后的可见边线变化。补线提供给队友原有偏差和舵机控制，不带入旧电控计算。

环岛故障检查通过原电控故障接口停车；超时不会冒充正常出环。故障重试仍通过队友原有按键逻辑，在新图像帧中复位。

此次是工程移植，未额外修改拐点阈值或用之前照片重新调参。已有模拟图像通过不等于实车环岛已跑通，仍需当前相机安装状态下的赛道序列验证。
