# RG3 舵机打角显示与控制模块分工

新增Ang显示，并将常用调参及速度策略移入独立TrackControl模块，减少后续修改main时与队友的冲突。控制参数保持RG2原值：P1.80、D2.00、补偿系数0.10，速度180/160/140/100。没有自动修改增益来掩盖反打。

## 文件位置

均相对于活动目录`project/restore_s1_R1/`：

| 文件 | 职责 |
| --- | --- |
| code/TrackControl.h | 速度、P/D默认值/按键步进、转向补偿、死区、D滤波等常用调参 |
| code/TrackControl.c | 弯道速度选择、出弯恢复及其状态 |
| code/Servo.c/.h | 舵机输出、中位与机械标定端点 |
| code/MotorPID.c/.h | 左右轮速度闭环与差速 |
| code/Screen.c | 屏幕文字、坐标、图像与标记绘制 |
| code/Screen.h | 屏幕类型、二值/灰度、刷新分频、图像位置和颜色 |
| user/src/main.c | 初始化与调用；既有PD计算仍保留，常用调参已迁出 |

旧Control.c没有编入当前工程，不在此次接回旧电控。

## 屏幕字段

| 字段 | 含义 |
| --- | --- |
| KEY RUN R3 / RG3 | 基础程序名 / 本次构建标记 |
| RUN / STOP | 控制是否已发车运行 |
| SPD | 手动基础速度设定，默认180，不等于每轮实际目标 |
| ERR | 本次用于循迹的图像偏差ErrUse |
| P / D | 舵机比例与微分系数，不是电机速度环PID |
| L / R | 左/右轮 实际编码器值 / 下发目标，计数/10ms |
| PWM | 舵机当前PWM数值，不是电机PWM |
| Ang | PWM减舵机中位；当前790为0，870为+80左，715为-75右。不是角度传感器读数，不是度数 |
| Cr | 十字是否激活，0否/1是 |
| Cs | 十字阶段：0正常、1候选、2进入、3内部、4退出 |
| Is | 环岛阶段：0正常、1接近、2等待入环、3入环、4环内、5出环、6对正、7恢复、8故障 |
| Dir | 环岛方向LEFT/RIGHT/-- |
| CAM | 当前有效图像状态OK/LOST，并非只表示摄像头硬件是否连接 |
| STOP | CAMERA有效图像超时，RING环岛保护，--未记录这两类保护原因 |
| > | 当前按键选择的SPD/P/D，C12切换、C15减、C14加，C13启停 |

图像上蓝/绿/红线为左边/中线/右边，灰色虚线是画面中心；黄色包括搜边参考列与十字补线，青色为环岛补线，品红和青色十字标记还包括十字角点，环岛当前观测点也用品红标记。需要结合Cr/Cs/Is判断，不能仅凭颜色区分状态。

## 过冲与反向打舵的排查

主程序实际控制是`u=P*error+D*filtered_delta+Steering_Boost(error)`。偏差快速减小时，D项会产生反向贡献，这是阻尼的一部分；反向太早/太大也可能使车摆动。不能仅凭“反打”就断言必须增大或减小D。

- Ang先反号、ERR还没反号：优先检查D贡献是否过强。可在相同速度下小步试D，例如2.0到1.8，再比较；D过小也可能使实际过冲加重。
- ERR已换号后Ang换号：偏差已越过参考线。除P外，重点检查额外补偿和弯速。
- STEER_BOOST_K当前0.10，偏差超过STEER_BOOST_START=12后会叠加额外转向，P降低了也可能仍然打得大。需要减弱时可单独小步试0.08、0.06；每次只改一项。
- STEER_D_FILTER_ALPHA当前0.5，减小可以更平滑，也会增加滞后，不能当成单向改善的参数。
- SERVO_U_LIMIT当前120，但舵机最终仍受Servo.h中+80/-75的标定范围限制。不要用改中位或扩大机械端点来处理过冲。
- 测试PID时固定速度，避免同时改速度、P、D、补偿，无法比较原因。架空能检查信号，实车过冲还需要带载验证。

## 编译与协作

Keil工程已登记TrackControl.c/.h。队友需要同时拉取工程文件和模块文件，重新打开工程再构建。仅复制main会缺少模块。

默认输出`project/mdk/Objects/keys_R3/rt1064_keys_R3.axf`，本次预编译固件`firmware/rt1064_keys_R3_RG3.axf`，清单`firmware/manifest_control_RG3.json`。烧录后标题旁应显示RG3，右轮速度行右侧显示Ang。

六组活动源码测试覆盖原四档速度、差速、按键、显示正负打角与布局、舵机及456项环岛场景。只构建，不自动烧录；实车调参需后续验证。
